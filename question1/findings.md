## 问题一 Q 实现初查
- 主评分流程为：8个列表指标取文档内均值 + 14个标量指标 → 缺失值用 A1 中位数填补 → A1 全局极差 Min-Max → 6个指定负向指标取补 → 熵权法 → 22项加权和。
- `compute_Q` 注释写“线性缩放”，实际只做 `[1e-6,1]` 截断；不过加权和本来就在 `[0,1]`，这不是当前低均值的直接原因，但注释与实现不完全一致。
- 当前代码把文档长度、句子数、唯一词比例、平均词长、unigram entropy、DSIR主题相似度等多项指标一律视作“越高越好”。这些变量是否满足单调质量方向需要回到数据说明核对，不能仅凭字段名认定。
- 使用全样本最小值/最大值会对长尾与极端值非常敏感；若 `word_count` 等有大离群值，大量正常样本会被压到接近0，从而明显拉低 Q 的绝对值。
- 熵权法会给分布稀疏、差异大的指标更高权重。若 DSIR 或长度类指标稀疏且经极差缩放后大量接近0，可能同时造成权重集中与 Q 均值偏低。
- 论文已明确报告：`rps_doc_word_count` 与 `rps_doc_num_sentences` 两项熵权合计超过 0.8，DSIR 类指标权重接近0；七个域的全指标 Q 排序与仅按 `fineweb_edu` 得到的域序秩相关接近0。
- 因此现有 Q 主要测量“文档规模/综合可用性”，而非纯语义质量。若其他队伍对长度做非单调处理、截尾/分位归一化或按质量维度分组赋权，绝对值和域排序都可能显著不同。
- 题面只强制方向统一、全量使用与给出聚合方式，并未指定必须使用熵权或全局极差缩放；与他人结果不同本身不能判错，但当前 Q 的语义命名和下游解释必须接受额外有效性审查。
- 现有权重中词数 0.41917、句子数 0.39879，合计 0.81796；第三大句末标点仅 0.03670。这个集中度已足以让 Q 基本等价于文档长度评分。
- 现有 Q 全样本均值 0.07988、中位数 0.07774、最小 0.03847、最大 0.79560。低绝对值主要来自评分尺度和权重结构，不能解释为“语料质量只有8%”。
- 发现结果陈述不一致：当前 `TABLE_q1_domain_Q.tex` 与 `problem_1_results.json` 报告扩展 arxiv 约 0.09330、github 约 0.07292；论文 `s3_q1.tex` 第94行仍写 arxiv 0.07932、github 0.07088，属于正文与结果产物未同步。

## 问题一 Q 独立复算
- 独立脚本从 A1 的 51230 条原始压缩 JSONL 重写了列表均值、缺失填补、方向转换、Min-Max、熵权和加权和；与 `output/q1_quality_scores.csv` 的逐行最大绝对差约 `2.9e-15`，域标签匹配率100%。现有实现计算正确。
- 权重集中度 HHI=0.3382，对应有效指标数仅约2.96个，远低于名义上的22个；但由于长度指标经极端最大值缩放后绝大多数接近0，它们对“平均 Q”的贡献并不等同于其权重占比，主要问题是尾部杠杆和域间偏置。
- `word_count`：中位数253、P99约10202、最大552671；`num_sentences`：中位数20、P99约758、最大25078。极值分别是P99的约54倍和33倍，证明全局极差缩放严重受离群值控制。
- 删除词数与句子数后，样本排序 Spearman=0.966，但七域排序 Kendall=0.619；说明大多数样本相对次序尚稳，域级结论已有明显变化。
- 将每项先按1%–99%截尾再熵权，样本排序 Spearman仅0.444、域序 Kendall仅0.333；说明当前排名高度依赖原始极值处理。
- 全22项分位秩等权的域序与当前 Kendall=0.333；三类指标组平衡后的域序 Kendall约-0.048；只用8个学习型质量信号的域序 Kendall约0.048。现有域级“质量”排序缺乏构念稳健性。
- 绝对 Q 值取决于缩放方式：当前均值0.080；去掉长度后的同类熵权均值0.429；分位秩方案均值按构造约0.5。因此不同队伍的 Q 数值不可直接比较，必须比较定义、域排序、外部效标和稳健性。
- A2/A3 流式全量复核显示，按当前代码使用 A1 归一化参照时，扩展 arxiv/github 应为 `0.07932/0.07088`；这与论文第94行一致，却与现存 JSON/表格的 `0.09330/0.07292` 不一致。现存结果产物很可能由旧版“扩展集各自归一化”逻辑生成，代码、论文、表格没有同步。
- 按官方 logits 标量化并沿用 A1 参照与新权重，A1 与扩展集仍高度一致：arxiv `0.26795` vs `0.26791`，github `0.15735` vs `0.15718`。因此修正预处理不会破坏跨集合稳定性，反而可保留这一优点。
- RedPajama/Gopher 的词数、句子数、平均词长、唯一词比例、unigram entropy本质上是描述性/过滤信号；其中词数和平均词长在经典数据过滤中采用上下界而非单调“越高越好”。当前统一设为正向单调指标，构念方向缺少依据。

## 官方字段语义核对
- SlimPajama-Meta-rater 官方数据卡说明：`fineweb_edu` 是单值列表；`ad_en=[has_ad_logit,no_ad_logit]`、`fluency_en=[not_fluent_logit,fluent_logit]`，推荐用 `argmax` 得到0/1评级；四个 ModernBERT PRRC 字段是0–5六档 logits，推荐 `argmax`；`qurater` 四个位置分别是写作风格、知识门槛、事实/轶事、教育价值。
- 当前 `compress_lists` 对上述8个字段统一求算术平均。对二分类/六分类 logits 求均值不表示类别、概率或期望等级，会丢失类别顺序信息；把 `qurater` 四个不同构念直接平均也缺少论证。
- 这构成实质性预处理错误，而非单纯“可选方法不同”。至少 `ad_en`、`fluency_en` 和四个 ModernBERT 字段必须按 logits 语义重新标量化；QuRating 应拆成四维或明确证明平均聚合合理。
- 官方数据卡还给出示例 Meta-rater 权重：各项大多约0.04–0.05，词数约0.0423、句子数约0.0458，与当前0.419/0.399的极端熵权集中完全不同，可作为外部方法对照但不能直接当本题唯一答案。
- 按官方数据卡标量化（binary/PRRC logits 用 `argmax`，FineWeb取单值，QuRating暂保留四维均值）后，其余仍沿用当前全局 Min-Max+熵权，新旧样本分数 Spearman约 `-0.051`，七域排序 Kendall约 `0.333`；新均值约0.1685。说明 logits 误处理对结果是决定性的。
- 官方标量化后再做1%–99%截尾熵权，新旧样本 Spearman约 `-0.062`、域序 Kendall约 `0.238`；采用官方标量化+分位秩+三类组平衡时，新旧域序 Kendall约 `0.048`。当前域级结论无法通过语义正确的替代预处理稳健性检验。
- 二分类结果显示 A1 中 `ad_en` 判为“无广告”约48300/51230，`fluency_en` 判为“流畅”约40111/51230；当前对两列 logits 取均值后再 Min-Max，完全没有保留这两个类别含义。
- 代码虽然定义了 `compress_lists_robust`（中位数/截尾均值），但全仓检索显示该函数未被调用；论文“稳健性另用截尾均值与中位数对照”的方法声称没有对应计算结果支撑。
- 现有能力审计 P1-C2 只验证全量读取、公式存在和结果文件存在；审计文件自身也注明“产物存在不代表内容正确”。它没有检查 logits 的语义处理、方向合理性或 Q 的构念效度，因此原 PASS 不能反驳本次问题。
- 当前冲突率也使用了由 `ad_en` 两个 logits 均值构造的“广告含量”，所以问题一后续4.96%冲突率同样受到该预处理错误影响，不能继续视为有效结论。

## 问题一 Q 审查结论
- 结论：算术实现可复现，但综合质量 Q 的数据语义处理不成立，当前结果不宜作为最终评分。
- 致命问题：对二分类/多分类 logits 统一取均值，破坏类别含义；修正后样本排序近乎不相关。
- 高风险问题：长度和部分自然语言信号被错误地设为单调“越高越好”；全局极差缩放受极端长文本控制；全局熵权有效指标数仅约3个。
- 一致性问题：当前代码、论文与存量 JSON/LaTeX 表对 A2/A3 的分数不一致；论文声称的列表中位数/截尾均值稳健性未实际执行。
- 影响范围：样本 Q、七域 Q 排序、A2/A3扩展分、冲突率、Q3基线 `Q0` 及依赖该基线的质量成本和转移点均需重算；Q1配比回归本身不直接依赖该Q，可单独保留后续再审。
- 建议重构：按字段语义解码 logits；对长度/平均词长等使用区间型适宜度；用 A1 经验分位或1%–99%截尾建立跨集合固定参照；按“模型评分/DSIR/结构信号”三组平衡，再在组内客观赋权；报告多口径域序与区间，并设置稳健性阈值。
